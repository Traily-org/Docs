## Règles d'usage

- **Linear est la source de vérité** pour l'avancement : une tâche = un ticket = une branche = une PR.
- Les **décisions** prises en sync ou dans le chat sont reportées dans le ticket Linear concerné **et** dans le salon Discord **#daily**.
- Les discussions techniques sur du code **en cours** (PR ouverte) se font **dans les commentaires de PR**.
- Les discussions techniques sur des parties **non en cours** se font **dans le salon Discord approprié**.
- Toute modification d'interface ou de comportement met à jour le **document concerné** dans ce dépôt (voir [OBS.md](./OBS.md), responsabilités transversales).

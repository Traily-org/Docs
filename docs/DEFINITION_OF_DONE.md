# Definition of Done (DoD)

Une tâche ou une user story est considérée comme **DONE** uniquement si tous les critères suivants sont remplis.

## Développement
- [ ] Le code est développé et correspond aux exigences du ticket Linear
- [ ] Le code respecte les standards de développement du projet
- [ ] Aucun TODO / commentaire critique restant

## Tests
- [ ] Des tests unitaires ont été ajoutés si nécessaire
- [ ] Tous les tests unitaires passent

## Qualité
- [ ] La pipeline CI est exécutée avec succès
- [ ] Aucun test ou build n’est en échec

## Revue de code
- [ ] Le code a été relu et approuvé par au moins un autre membre de l’équipe

## Documentation
- [ ] La documentation est mise à jour si nécessaire

## Validation
- [ ] La fonctionnalité a été testée en environnement de développement
